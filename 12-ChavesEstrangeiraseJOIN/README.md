# Aula 12 - Chaves Estrangeiras e JOIN

## 🎯 Objetivo
Colocar em prática o modelo relacional, criando relacionamentos entre tabelas por meio de chaves estrangeiras.

## 📚 Comandos utilizados

- DESCRIBE
- ALTER TABLE ... ADD COLUMN
- ALTER TABLE ... ADD FOREIGN KEY
- REFERENCES
- UPDATE ... SET ... = ... WHERE id = ...;
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- ON
- ORDER BY
- Uso de apelidos (AS) para tabelas e colunas

- ## ✅ Resultado

- Transformar um campo em uma chave estrangeira vinculada à outra tabela.
- Entender como a integridade referencial impede a exclusão de registros que estejam sendo utilizados por outras tabelas;
- Realizar consultas com INNER JOIN;
- Exibir todos os alunos, mesmo sem curso preferido, utilizando LEFT JOIN;
- Exibir todos os cursos, mesmo sem alunos associados, utilizando RIGHT JOIN;
- Entender a diferença entre JOIN, LEFT JOIN e RIGHT JOIN.

## 📚 O que eu aprendi

- Conceito de ACID: Atomicidade, Consistência, Isolamento e Durabilidade;
- Criação de chaves estrangeiras;
- Aplicação da integridade referencial;
- Relacionamento 1 (um para muitos);
- Consultas relacionando tabelas com JOINs;
- Uso de INNER, LEFT e RIGHT JOIN;
- Organização de consultas com apelidos de tabelas e ORDER BY.
