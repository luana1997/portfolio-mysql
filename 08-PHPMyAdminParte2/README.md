# Aula 08 - PHPMyAdmin (Parte 2)

## 🎯 Objetivo

Aprofundar o uso do PHPMyAdmin aprendendo a criar e manipular bancos de dados, tabelas e registros sem a necessidade de escrever todos os comandos manualmente. Demonstrando que cada ação realizada pela interface corresponde a um comando SQL, permitindo compreender melhor o funcionamento da linguagem e reforçando os conceitos já estudados.

## 📚 Comandos utilizados

## 🛢️Banco de dados
- `SHOW DATABASES`
- `CREATE DATABASE`
- `SHOW CREATE DATABASE`
- `DROP DATABASE`
- `USE`
  
## 📊Tabelas
- `CREATE TABLE`
- `SHOW TABLES`
- `DESCRIBE`
- `SHOW CREATE TABLE`
- `DROP TABLE`
  
## 📝Alteração da estrutura
- `ALTER TABLE` ... `CHANGE`
- `ALTER TABLE` ... `ADD`
- `ALTER TABLE` ... `DROP`
  
## 🔄Manipulação de dados
- `INSERT INTO`
- `SELECT * FROM`
- `UPDATE` ... `SET` ... `WHERE`
- `DELETE FROM` ... `WHERE`

- ## ✅ Resultado

- Criação de um banco de dados utilizando o PHPMyAdmin.
- Criação da tabela pela interface gráfica.
- Inserção, consulta, alteração e exclusão de registros pela interface.
- Visualização dos comandos SQL gerados automaticamente pelo PHPMyAdmin.
- Exclusão de tabelas e do banco de dados utilizando a ferramenta.

## 📚 O que eu aprendi

- Aprendi a utilizar o PHPMyAdmin para criar e gerenciar bancos de dados e tabelas.
- Entendi como visualizar os comandos SQL gerados automaticamente pelo PHPMyAdmin.
- Aprendi a configurar propriedades como `PRIMARY KEY`, `AUTO_INCREMENT` e `UNIQUE`.
- Compreendi como exportar um banco de dados para um arquivo .sql.
