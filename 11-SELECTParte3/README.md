# Aula 11 - Select (Parte 3)

## 🎯 Objetivo

 Aprofundar o uso do comando SELECT, aprendendo a diferença entre DISTINCT e GROUP BY, além de utilizar funções de agregação para contar, calcular médias e analisar dados agrupados. Também pratiquei filtros em agrupamentos com HAVING e uso de subconsultas para criar consultas mais avançadas e dinâmicas.

 ## 📚 Comandos utilizados
- SELECT
- DISTINCT
- GROUP BY
- ORDER BY
- COUNT
- AVG
- WHERE
- HAVING
- FROM
- Subconsultas (SELECT dentro de outro SELECT)

## ✅ Resultado

- Agrupamento registros por valores iguais utilizando GROUP BY.
- Contagem quantos registros existem em cada agrupamento com COUNT().
- Ordenar resultados agrupados com ORDER BY.
- Filtrar dados antes do agrupamento usando WHERE.
- Filtrar agrupamentos após a contagem utilizando HAVING.
- Calculo de médias de valores com AVG().
- Combinei seleção + filtro + agrupamento + agregação em uma única consulta.
- Utilização de subconsultas 

## 📚 O que eu aprendi

- Diferença entre distinguir valores (DISTINCT) e agrupar registros (GROUP BY).
- Como contar quantos registros existem em cada grupo usando COUNT().
- Como ordenar resultados agrupados com ORDER BY.
- Como filtrar registros antes do agrupamento com WHERE.
- Como filtrar resultados após o agrupamento com HAVING.
- Como calcular médias com AVG().
- Como combinar seleção, filtro, agrupamento e agregação em uma única consulta.
- Como utilizar subconsultas para comparar resultados.
